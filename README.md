# Учебный проект: Мини-Склад

Проект представляет собой учебную конфигурацию, разработанную на платформе 1С:Предприятие 8.3 в рамках изучения основ конфигурирования и программирования в 1С.
Цель проекта — изучить на практике принципы разработки в 1С:Предприятие.

Проект создан в учебных целях и может использоваться как база для дальнейшего расширения функционала.
Выполняется по учебному пособию с последовательным созданием и настройкой объектов конфигурации.


## Функциональность:

* Справочники:

  * Иерархический справочник "Товары" с табличной частью
  * Справочник "Контрагенты" с табличной частью
  * Справочник "Сотрудники" с табличной частью
  * Справочник "Склады" с предопределенным элементом

* Документы:

  * Реализация товаров
  * Поступление товаров
 
* Регистры:
  
  * Регистр накопления "Остатки товаров"
  * Регистр оборотов "Продажи"
 
* Отчеты:

  * Обороты по товарам
  * Товары

* Печатная форма документа "Реализация"

Прикладное решение находится в стадии разработки, объекты будут добавляться.

## Требования

* 1С:Предприятие 8.3
* Рекомендуемый режим: тонкий клиент

## Запуск проекта:

1. Создать новую информационную базу 1С без конфигурации.
2. Открыть созданную базу в режиме Конфигуратор.
3. Выбрать Конфигурация → Загрузить конфигурацию из файлов.
4. Указать каталог src/.
5. Дождаться завершения загрузки конфигурации.
